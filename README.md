# 🔧 Torque Certo Auto Center

Projeto acadêmico de desenvolvimento de um sistema web para uma oficina mecânica fictícia, criado com o objetivo de aplicar conceitos de levantamento de requisitos, desenvolvimento Front-End e sistemas de informação.

O **Torque Certo Auto Center** busca representar uma solução digital para modernizar o atendimento e os processos de uma oficina mecânica, oferecendo uma interface simples e organizada para acesso a produtos, peças e serviços automotivos.

---

## 📌 Sobre o projeto

A Torque Certo Auto Center é uma oficina fictícia especializada em manutenção preventiva e corretiva de veículos leves.

O projeto surgiu a partir de um levantamento de requisitos que identificou diversos processos realizados manualmente, como:

- Agendamentos;
- Controle de estoque;
- Orçamentos;
- Ordens de serviço;
- Cadastro de clientes e veículos;
- Controle de pagamentos;
- Histórico de manutenção;
- Pós-venda.

A proposta é evoluir gradualmente o sistema para centralizar essas informações em uma única plataforma.

---

## 💻 Aplicação Web

A versão atual representa o desenvolvimento inicial da interface do sistema.

O site possui um catálogo interativo onde o usuário pode navegar entre diferentes categorias e localizar produtos ou serviços.

### Funcionalidades implementadas

- ✅ Catálogo de produtos e serviços
- ✅ Categorias de carros, motos e serviços
- ✅ Pesquisa em tempo real
- ✅ Carrinho com contador de itens
- ✅ Cadastro de usuário
- ✅ Login de usuário
- ✅ Persistência de dados utilizando LocalStorage
- ✅ Interface responsiva para computadores e dispositivos móveis
- ✅ Links preparados para integração com WhatsApp e Instagram
- ✅ Navegação por categorias

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5** para estruturação das páginas
- **CSS3** para estilização e responsividade
- **JavaScript** para interatividade e lógica da aplicação
- **LocalStorage** para armazenamento local dos dados
- **Google Fonts (Poppins)** para tipografia

Não foram utilizados frameworks ou bibliotecas JavaScript externas.
